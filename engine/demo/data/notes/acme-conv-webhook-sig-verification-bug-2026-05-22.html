Bug: Webhook Signature Verification Failing on Express with Body Parser

Bug reproduction: the handleStripeWebhook function in src/payments/webhooks.ts was receiving a parsed JSON object instead of the raw Buffer. Stripe's stripe.webhooks.constructEvent requires the exact raw bytes of the request body to compute the HMAC-SHA256 signature.

The issue was in the Express app setup ? express.json() middleware was applied globally, including to the /webhooks/stripe route, which parsed the body before our webhook handler could access it as a Buffer. This broke signature verification with the error "No signatures found matching the expected signature for payload".

Fix: registered express.raw({ type: 'application/json' }) specifically for the /webhooks/stripe route before the global json middleware, and updated src/api/routes.ts to document that req.body must be a raw Buffer for this endpoint. Verified the fix with a Stripe CLI webhook replay.
