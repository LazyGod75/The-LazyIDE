JWT Library Selection ? jose over jsonwebtoken

We decided to chose jose over jsonwebtoken for JWT signing because jose is ESM-native and has first-class support for Ed25519 and RS256 algorithms. The jsonwebtoken package predates modern ESM and requires CJS interop shims in our build pipeline.

The decision also factored in bundle size: jose is tree-shakeable (only import what you use), whereas jsonwebtoken ships the entire crypto suite even when only HS256 is needed.

Updated src/auth/jwt.ts to use the jose SignJWT API and adjusted src/config.ts to expose jwtExpiresInSeconds and refreshTokenExpiresInSeconds as typed config fields.
