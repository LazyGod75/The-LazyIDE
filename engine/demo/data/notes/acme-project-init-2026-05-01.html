Acme SaaS Backend ? Project Kickoff

Initialized the Acme SaaS backend repository. We decided on a modular TypeScript architecture with separate modules for auth, payments, and API. This structure allows independent testing and deployment of each subsystem.

Set up the project structure: src/auth/, src/payments/, src/db/, src/api/, and src/config.ts. Each module owns its domain logic and exposes a clean TypeScript interface to other modules.
